# Software Tools Marketplace Build21

Cumulative Build20 plus real physical item and service listings.

## Added
- Service, machinery, vehicle, equipment and parts adverts.
- Up to 12 JPG, PNG or WEBP images per advert.
- Price, price type, description, location and seller contact.
- Public search and category/province filters.
- WhatsApp and call seller actions.
- Admin listing approval and rejection.
- Seller listing status API for active, paused and sold.
- Existing digital software checkout remains intact.

## Run
```
npm install
npm start
```
Open `http://localhost:3000/marketplace.html`.

Demo seller/admin headers remain from Build20 development baseline and must be replaced with proper production sessions before public launch.
